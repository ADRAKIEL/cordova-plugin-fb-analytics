Cordova Plugin · Facebook App Events · v1.3.4

FBAnalytics

FBAnalytics es un plugin nativo para Cordova que integra Facebook App Events en iOS y Android. Permite registrar eventos personalizados, compras, funnels y conversion values con una API simple.

v1.3.4: Migrado a FBSDK 13.x con API FBSDKAppEvents singleton para iOS.

Instalación

cordova plugin add cordova-plugin-fb-analytics

Características principales

  • Eventos personalizados
  • Compras con moneda
  • Pasos de funnel
  • Conversion values
  • Integración nativa iOS/Android

Cordova Plugin · Facebook App Events

FBAnalytics

FBAnalytics is a native Cordova plugin that integrates Facebook App Events for iOS and Android. It allows custom events, purchases, funnels and conversion values through a simple JavaScript API.

Installation

cordova plugin add cordova-plugin-fb-analytics

Main Features

  • Custom events
  • Purchase tracking
  • Funnel steps
  • Conversion values
  • Native iOS/Android integration

FBAnalytics FREE vs PRO

FREE

  • Custom events
  • Basic purchases
  • Simple funnel
  • JavaScript API

PRO (coming soon)

  • Auto‑tracking
  • Visual debug overlay
  • Parameter validation
  • Advanced funnels
  • SKAN 4.0 / 5.0
  • AEM advanced
  • External dashboard
